# Cloudflare 接手與查證

- **LOAD**：透過 CF MCP，依 [Cloudflare 資源與接手檢查](../docs/建置、驗證與運維/建置驗證與運維.md#cloudflare-資源與接手檢查) 以唯讀方式實測本專案使用的服務，確認帳號與資源，逐項回報已測讀取範圍、結果及未確認原因。以當次實測為準，不以工具存在、清單可讀或先前成功推定全部可讀；不透過寫入測權限，讀取成功不代表具有寫入權限。
- **涉及 CF 的分析、理解與規劃**：先讀相關文件，再依任務範圍核對程式、實際雲端設定、部署版本及必要執行結果；依 [AGENTS.md](../../AGENTS.md) 的原則辨識、查明及回報落差，無法查證的部分明列未確認。有效證據沿用與修改授權仍依該規則，不以文件描述或推測代替查證。
