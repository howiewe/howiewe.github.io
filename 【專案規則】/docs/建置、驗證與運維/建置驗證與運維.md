# 建置、驗證與運維

## 本機入口與依賴

[package.json](../../../package.json) 只提供 `npm run dev`，實際執行 `wrangler pages dev .`，以專案根目錄作為靜態資源及 Functions 入口。使用能執行鎖定版 Wrangler 的 Node.js/npm 環境，先以 `npm ci` 安裝 [package-lock.json](../../../package-lock.json) 內依賴。

瀏覽器函式庫由 `vendor/` 本地引用，包括裁切、排序、CSV 解析、條碼、畫面擷取及 PDF 匯出；部分頁面另依賴 Google Fonts，圖片也使用外部公開 URL。這是目前依賴狀態，沒有新增零外部依賴的長期限制。

## 環境與部署

| 綁定 | 用途 |
| --- | --- |
| `D1_DB` | 產品、分類、SSR 與 Sitemap 查詢 |
| `IMAGE_BUCKET` | R2 圖片上傳及清理 |
| `R2_PUBLIC_URL` | 上傳回應的圖片 URL 前綴，以及清理時識別 R2 key |
| `ASSETS` | SSR 取得靜態 HTML 模板 |

這些值由 Functions 執行環境提供。管理 API、公開 API 與 SSR 的環境檢查及失敗行為見 [API 與安全保護](../功能、資料與契約/API與安全保護.md)、[前端架構與 SSR](../架構與設計/前端架構與SSR.md)。

已透過 Cloudflare API 核對 Pages 專案 `kwanghwatw`，網域為 `kwanghwatw.pages.dev`，來源連接 GitHub `howiewe/howiewe.github.io` 的 `main`。目前建置指令、根目錄及輸出目錄欄位均為空。這是既有 Git 連接的部署入口，不另假設有本機發布腳本。

生產設定將 `D1_DB` 綁至 D1 資料庫、`IMAGE_BUCKET` 綁至 R2 Bucket `menu-images`，並提供 `R2_PUBLIC_URL`。另有 `AUTH_DOMAIN`、`POLICY_AUD` 環境變數，但目前程式沒有引用。預覽設定沒有列出對應的 D1、R2 與環境變數，不能假設預覽可提供完整功能。

儲存庫未包含 Wrangler 配置、D1 建表／migration、Access 策略或發布腳本／CI；雲端設定存在不代表本機具備相同環境。因此單純執行開發指令不能還原完整系統，本機或預覽測試需另外準備綁定、Schema 與隔離資料。

Access 目標與工具頁的覆蓋差異見 [API 與安全保護](../功能、資料與契約/API與安全保護.md)。R2 CORS 目前允許 `https://kwanghwatw.pages.dev` 與 `http://localhost:3000` 的 GET／HEAD；本機改用其他開發來源時，不能假設 PDF 圖片擷取可用。設定已核對，尚未以瀏覽器實測圖片擷取與登入流程。

`robots.txt` 是爬蟲指示，不能代替存取保護；其中 Sitemap 使用既有 Pages 網域，換網域時需與 Sitemap、canonical 及資源來源一併核對。未完成的部署維護事項見 [開發驗證與資料恢復](../../代辦/04-開發驗證與資料恢復.md)，工具頁保護範圍見 [輸出安全與存取保護](../../代辦/01-輸出安全與存取保護.md)。

## 驗證方式

目前沒有自動測試、lint、獨立 build 或測試資料腳本。按影響範圍選擇必要檢查，不宣稱沒有執行的驗證已通過。

- 文件／規則：核對本地引用、導覽、需求與現況的區分、已知問題的保存，以及相對起始基準的完整修改範圍；可用 `git diff --check` 檢查空白問題，新文件也要納入檢查。
- JS 語法：在 PowerShell 可將 `Get-Content -Raw -LiteralPath '檔案路徑'` 管線送入 `node --input-type=module --check`；HTML 內嵌腳本需另行檢查。語法通過不證明資料或瀏覽器行為正確。
- API／資料：在已具備 Schema 與測試資料的隔離環境檢查分類階層、查詢回應、圖片轉換、正常及失敗的產品寫入與刪除；使用替身的單位檢查不能宣稱驗證了真實 D1/R2。
- SSR／瀏覽器：檢查首頁、大廳、全產品、分類與產品直連；比較原始 SSR HTML 與 JS 載入後結果，並驗證搜尋、排序、分頁、彈窗關閉及返回。
- 管理／工具：在測試資料範圍確認編輯、分類刪除限制、圖片裁切與上傳失敗、CSV 配對與建檔；型錄檢查分類選取、筆數、長名稱、圖片、條碼、換頁及 PDF 輸出。
- 介面：按 [使用介面與內容](../使用介面與內容/使用介面與內容.md) 核對兩種主題、手機與桌面、斷點及必要鍵盤互動。

程式驗證與使用者實機驗收的權責依 [Agent 工作規則](../../../AGENTS.md)；純文件工作不要求使用者替代技術核對。上述為入口與檢查範圍，不代表已全部執行。

## 維護與故障定位

先按錯誤所在層檢查環境綁定、API 回應、Functions 日誌與瀏覽器訊息。SSR 查詢失敗可能仍回傳靜態模板；R2 清理失敗也不回滾 D1，不能只看 HTTP 成功就判定整條資料流完成。

Sitemap 的回應設定共享快取一天，抓取分類或產品失敗時可能仍輸出部分結果；需檢查內容及日誌。產品更新沒有額外的全站快取失效流程。本機未收錄備份、還原、監控或孤兒圖片掃描工具，必要操作需先核對既有雲端配置與資料恢復方式。
