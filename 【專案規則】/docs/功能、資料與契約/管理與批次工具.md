# 管理與批次工具

本專案提供管理者後台、批次上傳建檔以及型錄列印三大工具頁面，均位於 `/admin/` 管理區並使用管理 API。三頁採相同登入保護，舊網址導向與後端驗證見 [API 與安全保護](API與安全保護.md)。

---

## 1. 後台管理系統 (`/admin/` / `admin/index.html` / `js/admin/`)

後台主要分工如下：

- **`js/admin/admin-app.js`**：
  - 產品的完整 CRUD 與分頁查詢（`/admin/api/products`）。
  - 商品編輯/新增 Modal 表單控制、即時 EAN-13 條碼預覽與多圖 R2 上傳調度。
  - 產品編輯表單以桌面雙欄、手機單欄安排圖片及欄位，滾動範圍由 CSS 控制，實機效果仍需依修改驗證。
- **`js/admin/category-manager.js`**：
  - 分類管理 Modal 控制器，切換列表與編輯表單，以 `hidden` class 控制顯示。
  - 整合 `Sortable.js` 實現分類拖曳排序（`/admin/api/reorder-categories`）。
  - 分類階層瀏覽與堆疊歷史返回。
- **`js/admin/idb-cache.js`**：
  - IndexedDB 本地分類快取；雲端分類讀取失敗時嘗試回退，不代表產品離線讀寫或同步能力。

分類刪除由 API 阻擋仍有子分類或產品的情況，目前確認文字與此行為不一致；一般產品儲存與圖片上傳失敗也有狀態處理缺口，見 [待辦](../../代辦/待辦.md)。

## 2. 批次建檔工具 (`/admin/batch-upload` / `admin/batch-upload.html` / `js/tools/batch-upload.js`)

- **功能**：專門用於大量快速上架新產品。
- **工作流**：
  1. 上傳 CSV 產品清單（使用 `vendor/js/papaparse.min.js` 解析）。
  2. 批次選取多張圖片，由 `js/tools/batch-upload.js` 內的裁切佇列依序處理。
  3. 點選圖片與對應產品進行配對關聯。
  4. 先各自呼叫 `/admin/api/upload/:filename` 上傳配對圖片，再把成功取得的 URL 與產品資料以 JSON 送至 `/admin/api/batch-create` 寫入 D1。

CSV 欄位與分類路徑例子見 [下載範本](../../../templates/products_template_simple.csv)；分類以 `>` 分隔，後端按路徑找出或建立分類，未提供路徑時使用「未分類」。只有已配對的產品進入提交範圍；目前圖片上傳失敗可能被過濾後仍繼續建檔，不能視為整批原子操作。

管理頁與批次頁雖載入 `cropper-helper.js`，實際尚未呼叫其中的 `CropperQueue`，而是保留各自實作；批次頁的 Toast 與主題切換亦有本地邏輯。後續整合需保留各頁現有輸出格式及狀態回饋，見 [開發規範](../開發規範/開發規範.md)。

## 3. PDF 型錄列印工具 (`/admin/print-catalog` / `admin/print-catalog.html` / `js/tools/print-catalog.js`)

- **功能**：將系統內的分類與產品資料排版為可供列印與下載的專業型錄 PDF。
- **運作機制**：
  - 在 `js/tools/print-catalog.js` 內建立複選分類樹；勾選時連動後代與祖先狀態。雖載入 `category-utils.js`，尚未使用其中工具。
  - 以所選分類 ID 查詢產品，按主要分類分組並測量內容高度換頁；長產品名稱以 `shrinkTextToFit` 嘗試縮小字型。
  - 使用 `JsBarcode` 動態生成 EAN-13 條碼圖片。
  - 透過 `html2canvas` 渲染預覽，並使用 `jspdf` 匯出為 A4 格式 PDF 文件。

產品查詢有筆數上限，圖片亦需要可跨來源擷取；型錄完整性及輸出檢查見 [API 契約](API與安全保護.md)、[使用介面與內容](../使用介面與內容/使用介面與內容.md) 與 [建置、驗證與運維](../建置、驗證與運維/建置驗證與運維.md)。
