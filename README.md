# 專案導覽

光華工業產品目錄系統，提供訪客瀏覽產品與分類，管理者維護產品、批次建檔及匯出 PDF 型錄。公開前台供品牌展示、批發與外銷詢問使用；程式未提供購物車、付款或訂單流程。

## 接手閱讀順序

1. 必讀：[Agent 工作規則](AGENTS.md)。
2. 除僅執行 `load` 外，分析、討論及開發前必讀：[開發偏好](【專案規則】/開發偏好.md)、[專案長期要求：介面與裝置](【專案規則】/專案長期要求/介面與裝置.md)。長期要求只有深淺色模式與手機、電腦響應式支援。
3. 查看 [目前交接](【專案規則】/交接/目前交接.md) 與本次相關的 [待辦索引](【專案規則】/代辦/待辦.md)，辨識未完成工作；只讀取記錄不代表恢復實作。
4. 先用 [架構總覽](【專案規則】/docs/架構與設計/架構總覽.md) 建立資料流框架，再依下方地圖核對相關程式與驗證入口。文件提供背景，預期行為依已確認需求判定，實作以程式及必要驗證查證。

## 使用方式與主要分工

- 訪客從首頁進入分類探索、產品目錄與產品詳情；目錄支援搜尋、排序及分頁。
- 管理者從後台編輯產品與分類，使用批次建檔工具配對 CSV 與圖片，或選取分類產生 PDF 型錄。
- 公開 HTML 放在根目錄，管理頁與工具入口集中於 `/admin/`，靜態模板放在 `admin/`；CSS 與瀏覽器 JS 放在 `css/`、`js/`。第三方瀏覽器函式庫目前放在 `vendor/`，部分頁面另載入 Google Fonts。
- Cloudflare Pages Functions 負責前台 SSR、API 與 Sitemap；D1 保存產品及分類，R2 保存上傳圖片。
- 目前介面以繁體中文為主，部分固定文字為英文；桌面與手機樣式、深淺色及列印介面的實作範圍見 [使用介面與內容](【專案規則】/docs/使用介面與內容/使用介面與內容.md)。

## 文件維護

更新權限、時機、同步與收尾依 [Agent 工作規則](AGENTS.md)。正式文件保留目前維護所需的責任、關係、契約、限制、入口及必要理由，不轉錄完整程式或累積修改歷史；問題進度由交接或待辦保存。新增、整合或搬移文件時，維護此地圖及受影響的相對連結。
