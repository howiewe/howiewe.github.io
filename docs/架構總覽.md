# 架構總覽

本專案為**光華工業產品目錄系統**，全棧託管於 Cloudflare 基礎設施，採用無伺服器（Serverless）邊緣運算架構。

---

## 系統全棧地圖

```
[ 用戶端瀏覽器 ]
       │
       ▼
[ Cloudflare 邊緣網路 (Edge) ]
       │
 ┌─────┴────────────────────────────────────────────────┐
 │                                                      │
 │  1. 靜態資源 (HTML / CSS / JS / Vendor)               │
 │     ├── css/ (style.css, admin.css, print-catalog.css)│
 │     ├── js/  (業務腳本與共用工具模組庫)              │
 │     └── 由 Cloudflare Pages 直接快取分發             │
 │                                                      │
 │  2. 邊緣運算 (functions/)                            │
 │     ├── functions/_lib/        (高內聚共用模組庫)     │
 │     │   ├── db.js (D1 查詢)    ├── r2.js (圖片存儲)   │
 │     │   ├── seo.js (Meta/JSON) ├── injectors.js (SSR) │
 │     │   └── utils.js (轉義/響應)                     │
 │     ├── functions/[[path]].js  (SSR 主路由)          │
 │     ├── functions/api/         (寫入型 API 路由) 🔒  │
 │     ├── functions/public/      (唯讀型公開 API 路由) │
 │     └── functions/sitemap.xml.js (動態 Sitemap)      │
 │                                                      │
 └─────┬────────────────────────────────┬───────────────┘
       ▼                                ▼
[ Cloudflare D1 (SQLite) ]     [ Cloudflare R2 (Object Storage) ]
  儲存分類與產品關聯資料          儲存產品圖片二進位檔案
```

---

## 對外存取與保護架構

系統將前台展示與後台管理依安全性嚴格分流：

| 範圍 | 路徑 | 說明 | 存取保護 |
|---|---|---|---|
| **公開前台** | `/`、`/catalog*` | 品牌首頁、探索頁、產品目錄頁 | 無需認證（公開訪問） |
| **唯讀 API** | `/public/*` | 前端拉取分類與產品分頁 | 無需認證（強制只允許 `GET`） |
| **後台管理** | `/admin*`、`batch-upload.html`、`print-catalog.html` | 產品/分類 CRUD、批次建檔、型錄列印 | **Cloudflare Access**（Zero Trust 認證保護） |
| **寫入 API** | `/api/*` | 產品/分類之新增、修改、刪除、圖片上傳 | **Cloudflare Access**（Zero Trust 認證保護） |

## 前台四層瀏覽動線

前台頁面採用階層化動線（一層接一層）：

```
[第一層: 品牌首頁]  / 
    │
    │  (點擊「探索我們的產品」或「產品系列」)
    ▼
[第二層: 探索大廳]  /catalog/category 
    │  (展示精選分類與全部分類卡片)
    │
    │  (點選特定分類卡片)
    ▼
[第三層: 產品目錄]  /catalog/category/:id/:name 
    │  (展示特定分類產品網格 + 側邊分類樹)
    │
    │  (點選特定產品卡片)
    ▼
[第四層: 產品詳情]  /catalog/product/:id/:name
       (彈出 Modal 詳情，並同步更新瀏覽器網址與 SSR 支援)
```
