# 架構總覽

本專案為**光華工業產品目錄系統**，程式以 Cloudflare Pages、Functions、D1 與 R2 組成無伺服器架構。專案入口與文件分類見 [專案導覽](README.md)。

---

## 系統全棧地圖

```
[ 用戶端瀏覽器 ]
       │
       ▼
[ Cloudflare 邊緣網路 (Edge) ]
       │
 ┌─────┴────────────────────────────────────────────────┐
 │                                                      │
 │  1. 靜態資源 (HTML / CSS / JS / Vendor)               │
 │     由 Cloudflare Pages 直接快取分發                 │
 │     ├── css/ (依共用與頁面責任拆分的樣式)            │
 │     ├── js/ (customer, admin, tools, shared 模組)    │
 │     └── vendor/ (本地第三方瀏覽器函式庫)             │
 │                                                      │
 │  2. 邊緣運算 (functions/)                            │
 │     ├── functions/_lib/        (高內聚共用模組庫)     │
 │     │   ├── db.js (D1 查詢)    ├── r2.js (圖片存儲)   │
 │     │   ├── seo.js (Meta/JSON) ├── injectors.js (SSR) │
 │     │   └── utils.js (轉義/響應)                     │
 │     ├── functions/[[path]].js  (SSR 主路由)          │
 │     ├── functions/api/         (管理 API 路由)       │
 │     ├── functions/public/      (唯讀型公開 API 路由) │
 │     └── functions/sitemap.xml.js (動態 Sitemap)      │
 │                                                      │
 └─────┬────────────────────────────────┬───────────────┘
       ▼                                ▼
[ Cloudflare D1 (SQLite) ]     [ Cloudflare R2 (Object Storage) ]
  儲存分類與產品關聯資料          儲存產品圖片二進位檔案
```

## 對外存取與保護架構

系統將公開讀取與管理操作分流；管理端認證依賴 Cloudflare Access，程式內沒有額外的 Token 驗證。已核對的策略範圍及工具頁例外見 [API 與安全保護](API與安全保護.md)。

| 範圍 | 路徑 | 說明 | 存取保護 |
|---|---|---|---|
| **公開前台** | `/`、`/catalog*` | 品牌首頁、探索頁、產品目錄頁 | 無需認證（公開訪問） |
| **唯讀 API** | `/public/*` | 前端拉取分類與產品分頁 | 無需認證（強制只允許 `GET`） |
| **後台管理** | `/admin.html`、`/batch-upload.html`、`/print-catalog.html` | 產品/分類 CRUD、批次建檔、型錄列印 | Access 保護管理主頁；工具頁本身未列入目前策略，資料由管理 API 保護 |
| **管理 API** | `/api/*` | 管理端讀取、產品/分類之新增修改刪除、圖片上傳 | Cloudflare Access |

## 前台四層瀏覽動線

前台頁面採用階層化動線（一層接一層）：

```
[第一層: 品牌首頁]  /
    │
    │  (點擊「探索我們的產品」或「產品系列」)
    ▼
[第二層: 探索大廳]  /catalog/category
    │  (展示精選分類與分類卡片)
    │
    │  (點選特定分類卡片)
    ▼
[第三層: 產品目錄]  /catalog/category/:id/:name
    │  (展示特定分類產品網格 + 側邊分類樹)
    │
    │  (點選特定產品卡片)
    ▼
[第四層: 產品詳情]  /catalog/product/:id/:name
       (彈出 Modal 詳情，並同步更新瀏覽器網址與 SSR 支援)
```

SSR 從 D1 讀取資料並以 HTMLRewriter 注入 HTML 模板；目錄頁載入後由瀏覽器透過 `/public/*` 重新取得資料與處理互動。管理頁使用 `/api/*`，圖片先上傳 R2，再將公開 URL 與產品資料寫入 D1。具體契約見 [前端架構與 SSR](前端架構與SSR.md)、[資料庫與儲存](資料庫與儲存.md) 及 [管理與批次工具](管理與批次工具.md)。
