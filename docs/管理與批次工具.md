# 管理與批次工具

本專案提供管理者後台、批次上傳建檔以及型錄列印三大工具頁面，均受到 Cloudflare Access 安全保護。

---

## 1. 後台管理系統 (`admin.html` / `js/admin/`)

後台管理模組拆分為三大職責單一元件：

- **`js/admin/admin-app.js`**：
  - 產品的完整 CRUD 與分頁查詢（`/api/products`）。
  - 商品編輯/新增 Modal 表單控制、即時 EAN-13 條碼預覽與多圖 R2 上傳調度。
  - 完善的雙欄/單欄響應式滾動佈局支援（手機版全頁流暢滾動、桌面版 Flex 右欄滾動鏈）。
- **`js/admin/category-manager.js`**：
  - 分類管理 Modal 控制器，支援列表視圖 ⇄ 編輯表單之雙視圖平移動畫切換。
  - 整合 `Sortable.js` 實現分類拖曳排序（`/api/reorder-categories`）。
  - 分類階層瀏覽與堆疊歷史返回。
- **`js/admin/idb-cache.js`**：
  - IndexedDB (`ProductCatalogDB_CF`) 本地快取層，離線容錯儲存分類結構。

---

## 2. 批次建檔工具 (`batch-upload.html` / `js/tools/batch-upload.js`)

- **功能**：專門用於大量快速上架新產品。
- **工作流**：
  1. 上傳 CSV 產品清單（使用 `vendor/js/papaparse.min.js` 解析）。
  2. 批次選取多張圖片，進入 `js/shared/cropper-helper.js` 裁切佇列依序處理。
  3. 點選圖片與對應產品進行配對關聯。
  4. 一鍵呼叫 `/api/batch-create` 將圖片二進位與產品資料批次寫入 R2 與 D1。

---

## 3. PDF 型錄列印工具 (`print-catalog.html` / `js/tools/print-catalog.js`)

- **功能**：將系統內的分類與產品資料排版為可供列印與下載的專業型錄 PDF。
- **運作機制**：
  - 勾選欲列印的分類樹項目（使用 `js/shared/category-utils.js` 建立層級選單）。
  - 自動計算文字寬度並動態微調字型（`shrinkTextToFit`），確保長標題不溢出。
  - 使用 `JsBarcode` 動態生成 EAN-13 條碼圖片。
  - 透過 `html2canvas` 渲染預覽，並使用 `jspdf` 匯出為 A4 格式 PDF 文件。
