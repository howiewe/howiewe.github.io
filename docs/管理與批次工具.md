# 管理與批次工具

本專案提供管理者後台、批次上傳建檔以及型錄列印三大工具頁面，均受到 Cloudflare Access 安全保護。

---

## 1. 後台管理系統 (`admin.html` / `script-admin.js`)

- **功能**：產品的完整 CRUD、樹狀分類管理與視覺化拖曳排序。
- **快取機制**：使用瀏覽器 IndexedDB (`ProductCatalogDB_CF`) 快取分類資料；產品資料則直接向 `/api/products` 即時分頁拉取，不作本地過期快取。
- **圖片處理**：整合本地 `Cropper.js` 提供多圖旋轉、裁切與縮放功能，處理後直接上傳至 R2。

---

## 2. 批次建檔工具 (`batch-upload.html` / `script-batch-upload.js`)

- **功能**：專門用於大量快速上架新產品。
- **工作流**：
  1. 上傳 CSV 產品清單（使用 `PapaParse` 解析）。
  2. 批次選取多張圖片，進入 Cropper 裁切佇列依序處理。
  3. 點選圖片與對應產品進行配對關聯。
  4. 一鍵呼叫 `/api/batch-create` 將圖片二進位與產品資料批次寫入 R2 與 D1。

---

## 3. PDF 型錄列印工具 (`print-catalog.html` / `script-print-catalog.js`)

- **功能**：將系統內的分類與產品資料排版為可供列印與下載的專業型錄 PDF。
- **運作機制**：
  - 勾選欲列印的分類樹項目。
  - 自動計算文字寬度並動態微調字型（`shrinkTextToFit`），確保長標題不溢出。
  - 使用 `JsBarcode` 動態生成 EAN-13 條碼圖片。
  - 透過 `html2canvas` 渲染預覽，並使用 `jspdf` 匯出為 A4 格式 PDF 文件。
